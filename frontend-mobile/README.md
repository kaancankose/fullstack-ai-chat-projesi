# 📱 AI Chat (React Native)

Bu, Full Stack + AI Chat uygulamasının mobil sürümüdür.  
React Native CLI ile geliştirilmiştir.

## 🚀 Kurulum

```bash
npm install
npx react-native run-android
```

## ⚙️ Geçici URL'ler
Backend: `http://localhost:5000/api/messages`  
AI Servisi: `http://localhost:7860/run/predict`

## 🎯 Özellikler
- Gerçek zamanlı chat ekranı
- Duygu analizi (pozitif/nötr/negatif)
- .NET Backend ve Hugging Face AI entegrasyonu
